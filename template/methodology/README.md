# 项目方法

每次任务先读本页，再按下表阅读相关指引。任务跨多个阶段时，读对应的几篇；内容变化后重读。

| 任务 | 阅读 |
| --- | --- |
| 新建项目、设计功能、调整模块或信息流 | [设计](design.md) |
| 修改实现、修复问题、迁移已有项目 | [实施](implementation.md) |
| 检查成果、交付、判断是否完成 | [验收](acceptance.md) |

这里讲怎样设计和推进任务。具体权限和通用要求以 [项目规则](../AGENTS.md) 为准，模块要求在各模块 README 的规格中，AI 模块的处理要求在其「规则」中。文档目录解释项目采用方式和实现；已有正文用链接引用，不重复维护。

目录与模块入口见 [TREE.md](../TREE.md)。无法读取本页或任务所需章节时，说明影响，停止依赖缺失内容的操作。不设置“已读”标记；检查通过不能证明理解了文档或内容质量合格。
