# 实施

先读任务涉及的模块规格和实现，检查当前改动，确认已有成果及本次范围。按 [项目规则](../AGENTS.md) 完成开工检查、任务记录和回滚准备，不覆盖无关改动。

按已确认的设计做最小改动。发现需要改接口、信息连接、成员或验收标准时，先按边界取得确认，再继续相关操作。无法继续时记录已完成内容、阻碍和下一步，不把启动进程当成完成。

修改后同步模块登记、说明和相关产物；涉及项目全景来源时重新生成。具体命令见 [项目入口](../AGENTS.md) 和 [模块清单](../TREE.md)。临时文件按位置表放置，不混入正式文档。

完成针对性验证后进入 [验收](acceptance.md)。发现框架本身缺项时，按项目规则的「框架反馈」处理，不私自绕过通用规则。
