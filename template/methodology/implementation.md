# 实施

先核对工作区、现有文件与用户授权，保留可恢复版本，不覆盖无关改动。读取本次模块的 INPUT.md、OUTPUT.md、PROCESS.md、生效设置和相关实现；知识按流程需要读取，不强制通读。知识冲突按适用条件、版本判断，仍不明就问。

在授权范围内修改，配套说明和连接同步更新。新位置从通用模板重新配置全部位置相关内容，使用新标识，不带入原位置偏好、成果和历史；旧位置偏好不自动删除。改显示名不改稳定标识。

旧项目不得直接覆盖为新结构。先说明迁移范围、备份和兼容入口，获准后逐步迁移；升级比较旧模板、新模板和当前文件，保留配置及偏好，冲突问用户，通过检查后更新版本，失败恢复。具体见 [运行与维护](operation.md)。

结构变化后生成全景，再执行 [验收](acceptance.md)。遇到尚无实现的自动能力，说明需人工执行或项目实现，不能把文档约定当作已运行功能。
