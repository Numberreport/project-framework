# 验收

对照任务目标和模块规格，逐项确认产出是否满足要求。检查实际行为和必要的失败场景，不只看文件存在或命令成功。

按 [项目入口](../AGENTS.md) 运行收尾检查和模块验收。程序模块按规格判断结果；AI 模块脚本只查结构，内容质量仍需审阅。检查通过不能证明文档已经被理解，也不能代替内容审阅。

文档改动检查链接和职责是否一致；图形改动实际查看文字、连线与标签。项目全景需与登记同步，不能凭模块名称补造关系。

交付时说明完成内容、验证结果及尚未验证的部分。有阻碍就明确说明，不能把部分通过说成全部完成。提交和任务收尾按 [版本管理](../AGENTS.md#版本管理) 与 [收纳](../AGENTS.md#收纳) 执行。
