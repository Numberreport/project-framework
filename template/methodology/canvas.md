# 可编辑项目画布

在项目目录运行 `node scripts/canvas-server.mjs`，用浏览器打开终端显示的本机地址。停止该进程即关闭服务。需要 Node 18+，不安装其他依赖。

画布读取现有模块。拖动输出圆点到输入圆点建立连接，填写传递信息及可选条件；点击连线可以编辑或删除。拖动标题移动模块，进入组合编辑内部连接。支持撤销未保存的操作，切换组合或重新加载前提示放弃修改。

点击“查看变化并保存”，核对后保存。连接仍以各组合的 connections.json 为唯一依据，保留其他字段；节点位置另存 methodology/canvas-layout.json。保存会检查直接成员、必需输入输出连接及循环停止条件，并更新静态全景。检测到文件已被其他操作修改时拒绝覆盖，需要重新加载。

点击节点的“定义接口”，分别添加或移除输入、输出行，填写名称和要求；接口数量由行数决定，可以为零，也可定义尚未接线的接口。应用后立即显示在画布上，支持撤销；核对保存预览后，接口写入模块 INPUT.md、OUTPUT.md 的定义块，保留其余正文。格式见[模块模板](module-template.md#定义输入输出接口)。

旧模块没有定义块时，画布仍从“输入项 text”“输出项 text”等明确名称和已有连线临时识别接口。删除后仍被连线引用的接口会标成“未定义”，保留连线供修正，保存前须调整引用。组合接口同时受父组合和内部连线约束；需跨层修改时先在有关组合移除引用，再修改接口，最后接回新接口。

自动检查名称、数量、方向和连接引用，不会自动判断格式、单位或内容含义是否匹配。原有正文如含接口清单，变更后须同步核对，避免与定义块冲突。

第一版不创建模块，不执行任务，不展示运行状态。普通模块没有内部画布。连线只表示信息交接，不表示自动调度。画布服务仅监听本机，写操作需要当前页面的访问令牌；不要把服务转发到外网。

保存前确保文件可恢复；写入或全景更新失败时恢复本次连接和布局。异常断电不提供多文件事务保证。首次使用旧项目应先按实施指引迁移到当前格式。

工具验证：`node --test scripts/tests/canvas.test.mjs`。
