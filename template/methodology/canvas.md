# 可编辑项目画布

属 [方法首页 · 三层可视化](README.md#三层可视化) 的**第二层（底层结构可视化）**：方便开发者看清和改连接，不面向最终用户。静态全景见 [TREE.md · 项目全景](../TREE.md#项目全景)。面向用户的界面属第三层，按任务另建，不在本页规定。

在项目目录运行 `node scripts/canvas-server.mjs`，用浏览器打开终端显示的本机地址。停止该进程即关闭服务。需要 Node 18+，不安装其他依赖。

画布读取现有模块。拖动输出圆点到输入圆点建立连接，填写传递信息及可选条件；点击连线可以编辑或删除。拖动标题移动模块，进入组合编辑内部连接。支持撤销未保存的操作，切换组合或重新加载前提示放弃修改。

点击“查看变化并保存”，核对后保存。连接仍以各组合的 connections.json 为唯一依据，保留其他字段；节点位置另存 methodology/canvas-layout.json。保存会检查直接成员、必需输入输出连接及循环停止条件，并更新静态全景。检测到文件已被其他操作修改时拒绝覆盖，需要重新加载。

## 打包节点

先保存或撤销当前编辑，再勾选同一层的至少两个模块，点击“打包所选”。填写组合名称和唯一标识，查看目录移动、内外连线、接口及路径引用的变化，再确认保存。可以选择普通模块、组合模块或两者混合；保存后外层只显示新组合，点击“进入组合”继续编辑内部。

打包会把所选模块移入新组合的 modules/，保留原标识、设置、记录、成果和内部连线。每条跨边界的连线生成一个对应输入或输出接口，保留传递信息、适用条件及扩展字段；没有跨边界连线的一侧可以为零接口。原停止条件保留；打包新产生反馈回路但没有停止条件时，拒绝打包。节点位置随层级迁移，未选模块不移动。

新组合自动生成配套文件，状态为 pending。工具同步修改能识别的本地 Markdown 链接，以及 JS/TS 的相对导入和基于 import.meta.url 的 URL；不改写运行记录、成果或知识资料。计算路径、命令、其他语言及配置引用须人工核对。画布不生成运行入口；补齐流程和检验标准，验证业务行为后才能设为 ready。

预览可以取消，不写文件。预览后相关文件发生变化须重新预览；保存检查失败时恢复目录和文件。打包保存不属于“撤销”范围，操作前应保留项目备份或版本记录；含符号链接的模块须先处理真实目录后再打包。

## 定义接口

点击节点的“定义接口”，分别添加或移除输入、输出行，填写名称和要求；接口数量由行数决定，可以为零，也可定义尚未接线的接口。应用后立即显示在画布上，支持撤销；核对保存预览后，接口写入模块 INPUT.md、OUTPUT.md 的定义块，保留其余正文。格式见[模块模板](module-template.md#定义输入输出接口)。

旧模块没有定义块时，画布仍从“输入项 text”“输出项 text”等明确名称和已有连线临时识别接口。删除后仍被连线引用的接口会标成“未定义”，保留连线供修正，保存前须调整引用。组合接口同时受父组合和内部连线约束；需跨层修改时先在有关组合移除引用，再修改接口，最后接回新接口。

自动检查名称、数量、方向和连接引用，不会自动判断格式、单位或内容含义是否匹配。原有正文如含接口清单，变更后须同步核对，避免与定义块冲突。

## 范围与恢复

画布可通过打包创建组合，不创建普通模块、不执行任务、不展示运行状态。普通模块没有内部画布。连线只表示信息交接，不表示自动调度。画布服务仅监听本机，写操作需要当前页面的访问令牌；不要把服务转发到外网。

保存前确保文件可恢复；写入或全景更新失败时恢复本次连接和布局。异常断电不提供多文件事务保证。首次使用旧项目应先按实施指引迁移到当前格式。

工具验证：`node --test scripts/tests/*.test.mjs`。
