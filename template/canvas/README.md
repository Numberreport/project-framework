# 画布

画布以正式项目结构为依据，默认以只读模式打开。可以浏览、缩放、展开组合和查看配套文件。

正式画布与 `run.mjs` 共用 `structure.mjs` 读取结构；节点、接口和连线没有第二份正式定义。基础模块为 ready 时必须登记真实本体入口。入口失效或连接指向不存在的接口时，正式画布拒绝读取，统一执行入口也拒绝运行。草稿仍是独立试改副本，不参与正式执行。

## 启动

```bash
node canvas/canvas.mjs
```

打开终端显示的本机地址。点击“草稿”新建或打开一份草稿，进入编辑模式。每份草稿从当前正式项目复制，独立保存在 `.canvas-drafts/`，可以重命名、删除或复制路径。正式结构有变化时，草稿列表会提示“基于旧版项目”。

编辑模式中的连线、位置、平移、缩放和展开状态会自动保存到当前草稿。切换草稿或返回显示模式前先保存。保存失败时留在当前草稿，可以在模块抽屉中点“立即保存”重试。把草稿路径交给智能体，再说明你的调整思路。

智能体采纳草稿时，先核对草稿与当前正式项目的差异，再修改正式模块登记、组合归属、接口、连接和受影响的代码或提示词，最后检查正式画布。删除模块还须清除正式目录、相关连线及失效调用；不能只隐藏卡片，也不能用草稿整体覆盖正式项目。纯布局或样式调整可只修改相应画布文件。

以下编辑操作均在草稿中进行。

## 节点与接口

普通节点始终显示全部输入、输出，输入在左、输出在右。拖动标题移动节点；右上角齿轮编辑接口，每项填写标识和说明。标识只用字母、数字、下划线、短横线，同一方向不能重名。改名同步连接，删除已连接接口前列出受影响连线。

“配套文件”打开 README、检查标准、登记表，以及登记表指定的执行和验收文件，只允许读取模块目录内的文件。当前项目或组合的文件和设置在左侧抽屉中。

点击节点选中，Ctrl（Mac 用 Command）加点击多选，点击空白取消。在空白处按住左键拖动可框选，与选框相交的本层模块和独立输入输出节点会选中；Ctrl／Command＋框选追加选择，Esc 取消本次框选。组合输入输出对应节点不参与选择。选中两个以上时出现“组成组合”。左侧也可以勾选；节点上不放常驻勾选框。

空白处右键可添加通用节点、输入节点和输出节点。点击“添加通用节点”立即创建“未命名节点”，自动生成唯一标识，在当前层 modules/ 下生成真实模块目录及 README、module.json、VALIDATION.md，状态为 pending，默认带 input 输入端口和 output 输出端口，可直接连线。名称、职责以及多个输入、输出以后通过齿轮设置填写，不在创建时弹表单。重复标识拒绝创建，写入失败清理新目录。

输入、输出节点每个代表一项材料或结果，仅作定义：

- 输入节点淡绿色，例如“用户上传文件”，从输出连接点交给处理节点。
- 输出节点淡橙色，例如“交付报告”，通过输入连接点接收处理结果。
- 独立节点不要求对应外层接口。需要对应时，在设置中选“在组合外显示此接口”。

## 内外关系与组合

项目整体不画成普通节点。项目或组合有几个外部输入、输出，内部就分别显示几个对应节点，标注“组合输入”或“组合输出”。它们和独立节点外形相同，但来源不同：对应节点从外层接口定义直接生成，不重复保存。

外层新增、改名、删除接口时，内部对应节点同步变化。取消对应会保留内部节点和连线，移除外层接口；操作前提示会移除外层相关连线。

选中至少两个节点后点“组成组合”，自动生成唯一标识，以“未命名组合”直接打包；名称以后在设置里修改。程序先校验再移动目录、生成接口和重接连线，不再弹出填写和确认窗口。内部连接保留，跨边界连接通过新组合接口和内部对应节点交接。同一个来源、同一个输出的分支共用接口；不同来源即使同名也不合并，必要时追加数字避免冲突。独立输入、输出节点可以一起打包。

新组合处于 pending，需补齐职责和检查标准再改为 ready。“展开内部”在原位置显示内部画布，可继续编辑和嵌套；收起后仍保留内部草稿。点击外层接口会展开并突出内部对应节点。“进入组合”单独查看这一层，导航可返回上层。

## 连线与布局

鼠标移到节点上时，与它直接相连的输入、输出连线及箭头会加深高亮，连线同时加粗；移开后恢复。普通节点、组合节点和输入输出节点均适用。

AI 新建或调整节点、连接后，须整理布局并查看整体效果：按处理顺序和分支安排节点，留足间距，避免节点重叠或挤在一起；减少连线交叉、重叠和穿过无关节点，避免多条线挤成一团。检查整体和展开后的组合内部，确保节点、接口文字和连线走向清楚可辨，再保存布局。不能只确认连接正确，也不能仅靠缩小画布掩盖拥挤。

从输出接口整行拖到输入接口整行，或先点击输出再点击输入。接上即建立连线并自动保存，不弹设置窗口。传递内容默认采用输出接口说明，没有说明时采用接口名称；已有连线的内容和条件保留。重复连接同一对接口不生成重复线。连线统一使用青蓝实线，末端带箭头。已有文件中的类型标记保留，画布不再区分或设置类型。悬停显示说明，双击连线直接删除并自动保存。

按住鼠标滚轮（中键）拖动画布，可向任意方向平移，不受滚动边界限制，不改变节点位置。Ctrl＋滚轮以鼠标位置为中心缩放，范围为 40%—150%；普通滚轮仍用于滚动。右下角也可控制缩放。节点位置、缩放和组合展开状态写入布局文件；删掉布局只会重新排布，不影响项目结构。

## 文件对应与保存

| 内容 | 唯一来源 |
| --- | --- |
| 普通模块及组合 | modules/ 下的目录及 module.json |
| 输入、输出接口 | 对应 README 输入、输出小节的 interfaces 代码块 |
| 层内连接、独立输入输出节点 | 所属层 connections.json |
| 位置、缩放、展开状态 | 根目录 canvas-layout.json |

独立节点记录在可选的 ioNodes 数组中，每项包含 id、type（input 或 output）、name、description。其连接接口固定为 value，连接端点仍使用 module 和 port。旧文件没有 ioNodes 时视为空数组。

组合内部对应节点沿用 $self：组合输入在内部是连接来源，组合输出在内部是接收端。画布显示的是每项接口对应的独立节点，不是一个整体卡片。结构检查也识别 ioNodes，校验方向、标识与连接引用。

界面通过 /api/project 读取正式项目或所选草稿。/api/save、/api/settings 和打包接口仅允许写入当前草稿。接口设置、对应转换及删除会更新涉及的 README 和连接文件，其他正文保留。保存时核对结构文件版本，发现外部修改拒绝覆盖。涉及多个文件时，写入失败恢复原文件。

页面每四秒及重新获得焦点时检查文件变化：无草稿自动更新；存在草稿时保留并提示冲突。冲突后先自行记录草稿、核对外部修改，再刷新重新编辑，不提供强制覆盖。浏览器刷新不被离开提示拦截，因此未保存草稿会丢失。

正式版本检查包含本体代码、提示词和资料。底层结构无效或读取失败时，正式画布隐藏旧图并持续提示异常；修复后自动恢复。`runProject` 在每次接力前后核对同一版本，避免结构已变而继续使用旧结果。沿用原执行入口的项目也须验证实际调用与正式结构一致，详见 [正式执行](../README.md#正式执行)。

服务只监听本机，文件读取限制在项目中；不读取或更改 workspace/ 运行数据。

## 验证

```bash
node --test tests/*.test.mjs canvas/tests/*.test.mjs
node check.mjs
```

使用临时项目覆盖多接口编辑、改名同步、独立节点建立及取消对应、两层组合、打包边界、同源分支、同名不同源、保存冲突和写入失败恢复。浏览器另行验证齿轮、配套文件、添加节点、组合展开收起、草稿保留和刷新，不能以旧测试通过代替这些操作验证。

正式结构变更使用同一份具体输入，分别核对实际处理、正式结构和画布。删除后确认目录、连线和失效调用已清除，实际运行不再调用被删模块；在临时副本中去掉 `canvas-layout.json`，重新读取画布，节点、接口、组合归属和连线应仍可从正式文件完整重建。涉及 AI 或外部服务时可用受控执行方式验证调用关系，不要求为验收发起付费任务；这不能替代业务内容验收。
