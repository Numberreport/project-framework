# 处理流程

1. 明确输入 text 和启动指令，读取本模块配套文件及生效设置。
2. 按 connections.json 将输入交给直接成员，再接收成员输出；成员目录是唯一清单。
3. 向调用者交付 text；仅在要求保存时写入正式成果。

示例入口：`node implementation/run.mjs "一月。二月。三月。"`。收到输入但没有指令，不自动运行。此示例不接业务检验模块，不能宣称已完成业务检验；维护验收另行验证示例行为。

失败、授权、复用、分身、保存和恢复按 [运行与维护](methodology/operation.md)；本示例无外部工具和常驻进程。不通过内部成员绕开授权。
