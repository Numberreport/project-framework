# _example

> 这是样板，用完删掉这个目录，或者改名成真实模块。
> 「谁处理」以「程序：」或「AI：」开头。程序模块靠验收脚本判对错；AI 模块必须有「规则」一节，验收脚本只查结构，内容要人审。
> 模块不写自己属于哪个组合，组合关系只写在组合的「成员」里，样板见 `_example_combo`。

## 输入

什么：一段文字。
从哪来：外部

## 输出

一段文字。

## 谁处理

程序：`impl.mjs`，按「规则」一节处理。

## 规则

把输入的第一句话原样输出，其余句子倒序接在后面。

## 什么时候跑

手动触发。

## 怎么算做对

输出不为空，第一句不变，其余句子倒序。

验收命令：node modules/_example/verify.mjs

## 失败怎么办

重试一次，还失败就停下等人。
