# 处理流程

由当前智能体按 [操作指引](implementation/instructions.md) 将一项框架反馈整理为可公开的 Issue，并交付实际结果。不是无人值守的后台程序。

1. 接收反馈或授权工作中发现的问题，读取本模块输入、输出、检验标准及生效设置。
2. 判断是否属于通用框架，整理最少必要信息并核对隐私。
3. 查询相似 Issue，重复则交付已有链接。
4. 根据确认模式或明确自动授权决定是否提交；需要询问就暂停，不把一次授权写成长期偏好。
5. 提交前按 VALIDATION.md 审阅正文，通过后调用 GitHub 工具；核实结果并交付。

授权不清、隐私无法安全去除时先询问；工具不可用或查重失败时只交付安全草稿。提交结果未知先查询，不盲目重试。具体分支与工具步骤只在操作指引维护。

本模块不执行框架修复、规则修改、评论追加或 Issue 关闭，也不以“开启自动反馈”取得这些权限。
