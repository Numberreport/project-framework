# 反馈检验标准

检验需要原始意见或发现依据、本次准备公开的内容、生效设置与授权，以及查重和提交工具的实际结果。

- 问题针对通用框架，事实有依据，不把项目特例或未核实猜测写成框架缺陷。
- 一件事一个 Issue，标题清楚，正文具备现有表单五项；不编造未知文件、事实或临时处理情况。
- 不含账号、密钥、个人信息、项目路径、业务数据或其他项目隐私；不能安全去除就不提交。
- 已完成相似问题查询；已有同类反馈返回链接，不自动重复创建、评论、重开或关闭。
- 本次提交有明确同意，或已生效的自动反馈授权确实覆盖该问题、公开目标及提交行为；不能由安装模块或同意修改推定。
- 链接及成功状态来自实际工具结果或后续查询；工具失败、状态未知不伪装成功，不重复提交未知结果。

隐私、问题归类和授权需智能体实际判断。配置检查通过不能证明这些判断正确；未实际提交不能声称线上流程已验证。
