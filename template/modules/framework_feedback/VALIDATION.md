# 检查标准

需要原始意见、准备公开的完整内容、生效设置，以及查重和提交的实际结果。

- 问题是通用框架的问题，有依据，不把项目特例或猜测写成框架缺陷。
- 一件事一个 Issue，标题清楚，正文五项齐全，不编造。
- 不含账号、密钥、个人信息、项目路径、业务数据或其他项目隐私；去不干净就不提交。
- 已查过已有 Issue；有同类就给链接，不重复创建、评论、重开或关闭。
- 提交有明确同意，或生效的自动反馈授权确实覆盖这次问题和目标；安装模块或同意修改框架都不算。
- 链接和成功状态来自实际结果。工具失败或状态不明时不报成功，也不重复提交。

隐私去除、问题归类和授权判断要靠人。检查脚本通过不代表这些判断对。
