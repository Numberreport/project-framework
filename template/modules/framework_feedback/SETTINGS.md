# 设置

## 默认值

- 反馈目标：Numberreport/project-framework 的 GitHub Issues。只投通用框架意见，不转投其他仓库。
- 提交模式：先确认。展示准备公开的标题和正文，使用者同意后再提交；同一内容已明确授权的，不重复问。
- 自动反馈：未开启，授权范围为空。
- 运行记录保存期限：永久
- 允许外部工具付费：不允许，需要时先问

## 当前偏好

无。沿用默认的先确认模式。

开启自动反馈时，先说明拟保存的模式、范围、公开目标，以及它只作用于本位置，再按项目的确认方式记录。写入“自动提交”的条目必须写明适用的问题范围、目标仓库和授权依据；含糊或冲突时先问。撤销后恢复先确认。

安装本模块、同意修改框架、同意这一次反馈，都不等于开启自动反馈。
