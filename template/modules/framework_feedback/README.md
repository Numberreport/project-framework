# 框架反馈

使用框架时有意见，可以在对话中说“反馈框架问题”，或使用 [GitHub 反馈表单](https://github.com/Numberreport/project-framework/issues/new?template=framework-feedback.yml)。本模块只反馈通用框架，项目自身的功能问题交给该项目处理。

- [输入要求](INPUT.md)、[输出要求](OUTPUT.md)、[处理流程](PROCESS.md)、[检验标准](VALIDATION.md)。
- [默认设置](settings/DEFAULTS.md)、[当前位置设置与偏好](settings/PREFERENCES.md)。
- 执行入口：[智能体操作指引](implementation/instructions.md)。由当前智能体执行，需要已授权访问目标仓库的 GitHub 工具；不内置账号、密钥、后台服务或自动上报程序。

默认先展示内容再确认。使用者明确开启自动反馈并指定范围后，可在该范围内自动提交；本模块的安装、介绍或一次反馈授权不等于开启自动反馈。隐私、重复和授权仍须核对。

本模块是项目的直接成员，按需调用，不参与文字重排示例。配套文件齐全只说明配置就绪，不代表 GitHub 已连接或反馈已提交。
