# 输出要求

result：明确状态，并按情况附链接或草稿。

- 已提交：工具返回或事后查到的 Issue 链接。
- 已有反馈：对应的 Issue 链接和一句说明，不重复创建，也不追加评论。
- 待确认：准备公开的标题、正文，以及要使用者确认的问题。
- 未提交：原因和一份可以安全交付的草稿。
- 状态待确认：提交没拿到明确结果的，给安全摘要并继续查，不说成功也不说失败。

正文统一五项：遇到的情况、问题在框架哪处、建议怎么改、影响哪些文件、是否已临时变通。不知道写“未确定”，没变通过写“无”。标题只概括一个问题。

结果直接在当前对话返回。明确要求保存时才留存，不保存凭据。
