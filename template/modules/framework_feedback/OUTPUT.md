# 输出要求

输出项 result：明确状态，并按情况附链接或草稿：

- 已提交：经工具返回或后续查询确认的 Issue 链接。
- 已有反馈：对应 Issue 链接和简短说明，不重复创建或追加评论。
- 待确认：准备公开的标题、正文及需要确认的问题。
- 未提交：原因及可安全交付的草稿；纯项目问题说明不属本模块范围，不伪造成框架草稿。
- 状态待确认：本次提交的安全摘要及可用任务信息，继续查询，不声称提交成功或失败。

草稿和正式正文沿用目标仓库现有表单的五项内容：遇到的情况、问题在框架哪处、建议怎么改、影响哪些文件、是否已临时变通。未知项写未确定，未变通写无。标题概括一个问题，不扩写为多个无关建议。

在当前对话返回结果；只有明确要求保存时，按项目保存规则留存安全草稿或已确认链接，不另建公开日志，不保存凭据。
