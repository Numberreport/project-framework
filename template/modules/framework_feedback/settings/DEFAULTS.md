# 默认设置

- 反馈目标：Numberreport/project-framework 的 GitHub Issues；仅通用框架意见，不自动转投其他仓库。
- 提交模式：先确认。展示拟公开标题和正文，取得使用者同意后提交；已明确授权的同一内容不重复询问。
- 自动反馈授权范围：无，默认未开启。
- 运行记录保存：永久，仅在产生需要保存的任务记录时适用。
- 允许外部工具付费调用：不允许，需要时询问。

自动模式须使用者明确开启，并说明适用范围，方可覆盖默认模式。它不授权私有内容公开、跨仓库提交、重复创建、评论或关闭 Issue，也不覆盖更严格的个人规则。设置读取顺序见 [运行与维护](../../../methodology/operation.md)。
