# 检查标准

验收需要原始请求、适用的正式规范、实际读取材料和报告；复查还需上次报告和修改内容。

- 提示词清单包含识别依据，覆盖主提示词、分情况、备用及嵌入指令；没有把抽查或未还原的动态文本写成完整检查。
- 规范问题引用现行正式依据，阅读风险与硬性违规区分；问题有可定位原文和具体影响，不按个人风格挑错。
- 不因篇幅长判错，不强制简单任务加章节；正常引用、代码示例、机器接口 JSON 和必要资料不被误报。
- 建议对应问题，保留必要限制、例外和选择条件；没有修改被检查内容或交付整份重写稿。
- 未读材料、规范歧义及执行证据不足均如实说明，不宣称已证明模型效果；复查核对原问题和关联内容，不仅看字数变少。
- 报告保存位置在指定项目 workspace/ 任务目录内，正文、实际文件及返回路径相符；失败不报成功。

结构检查不能证明阅读判断正确，需结合具体材料审阅报告。
