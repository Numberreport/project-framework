# 项目口径检查

## 职责

检查项目中同一事项的规定和实际做法是否一致，只报告问题，不修改被检查内容。由当前智能体读取并执行[主提示词](implementation/prompt.md)，不内置模型账号。

## 输入

接收 request：项目位置、检查范围（修改后检查或全项目检查）、任务目录；修改后检查还须提供改动文件和改动内容。复查时提供上次报告。任务目录须位于该项目的 workspace/ 下。

```interfaces
[{ "name": "request", "description": "项目位置、检查范围、任务目录，修改后检查的改动信息及复查所需的上次报告" }]
```

## 输出

交付 report：检查报告正文和已保存路径；无法保存时明确说明，仍返回正文。报告是检查产物，不是项目规则。

```interfaces
[{ "name": "report", "description": "检查报告正文、保存路径或未能保存的原因" }]
```

## 处理流程

按[主提示词](implementation/prompt.md)读取项目、比较依据并形成报告，以[检查标准](VALIDATION.md)验收。本模块在画布上保留独立节点，不连接根项目的业务流程；可在对话中要求“检查项目口径”，提供上述输入。需要程序调度时，对本模块目录调用 runProject，并由调用方提供具有项目读取和报告保存能力的 executeAI。

## 没完成时

缺项目位置、范围或改动信息时，说明缺项，不猜测。材料缺失、读取失败或检查未完成时返回受限报告，不声称整个项目通过。修复由当前智能体处理，修复后重新调用本模块复查。
