# 检查标准

验收需要原始请求、实际读取的项目材料、检查报告；复查还需上次报告和修复内容。

- 范围与实际读取相符，修改后检查覆盖关联规定和实现；遗漏、排除及读取失败均可核对，不将抽查写成全查。
- 问题有可定位位置和原文依据，解释同一事项在什么条件下不一致，影响与建议具体。
- 正常引用、条件明确的多种做法和合理分工不被误报；无依据的取舍列为待确认。
- 没有问题使用限定范围的结论；缺材料或未完成时明确限制，不声称整体通过。
- 复查逐项核对旧问题，并检查关联内容和新冲突，不仅确认文字被修改。
- 未修改被检查内容，报告只保存到指定任务目录；返回路径与实际保存内容相符，保存失败如实说明。

结构检查只能验证登记、接口和文件等结构，不能证明以上内容判断正确。
