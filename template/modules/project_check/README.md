# 项目自检

## 职责

检查项目的口径一致、文档可读和整体衔接，找出冲突、阅读障碍和流程缺口。只报告问题，不直接修改项目。由当前智能体执行[主提示词](implementation/prompt.md)。

## 输入

接收 request：项目位置、检查范围（改动检查或全项目检查）、任务目录（位于该项目 `workspace/` 下），以及可选的检查维度（默认全部：口径、可读性、整体）、改动内容、复查时的上次报告和已有验证证据。

```interfaces
[{ "name": "request", "description": "项目位置、检查范围、任务目录，及可选的检查维度、改动信息、上次报告和验证证据" }]
```

## 输出

交付 report：自检报告正文和保存路径；保存失败时返回正文及原因。

```interfaces
[{ "name": "report", "description": "项目自检报告正文、保存路径或保存失败原因" }]
```

## 处理流程

在对话中要求“项目自检”（或指定只查口径、可读性、整体中的某一项），由当前智能体按[主提示词](implementation/prompt.md)执行，以[检查标准](VALIDATION.md)验收。本模块独立存在，不连入业务流程。

## 没完成时

缺少项目位置、范围或改动信息时说明缺项，不猜测。材料缺失、无法读取或缺少实测证据时，交付受限报告并说明限制，不声称项目全部通过。修复由当前智能体完成，修复后可再次调用复查。
