# 流程引导

## 职责

解释当前步骤、展示待确认成果、整理用户决定。执行顺序、保存和恢复由执行入口负责，本模块不调用业务模块，不替代质量检查。

## 输入

接收 request：正式执行计划、执行入口返回的当前状态，以及用户本次原话（尚未答复时可不提供）。待确认状态须包含成果正文、确认标识和下一步；若成果在文件中，还须提供当前内容和版本核对结果。材料不足时不能推断用户同意。

```interfaces
[{ "name": "request", "description": "正式计划、当前执行状态与成果、可选的用户原话和文件版本核对结果" }]
```

## 输出

交付 guidance：面向用户的简短说明、一个待回答问题（无需提问时为空）、整理后的决定（无明确决定时为空）。决定包含当前确认标识和 approve（同意）或 revise（修改）；修改时还包含按原模块输入接口整理的完整输入。

```interfaces
[{ "name": "guidance", "description": "步骤说明、一个待回答问题或空值、用户明确决定或空值" }]
```

## 处理流程

当前智能体按[主提示词](implementation/prompt.md)处理，以[检查标准](VALIDATION.md)验收。开始任务时介绍流程；执行入口返回 waiting 后展示成果并等待真实答复，再整理决定交回执行入口。completed 才表示完成。

本模块独立显示，不插入业务连线。程序接入时可对本模块目录单独调用 runProject，由 executeAI 连接实际智能体；得到的决定须与用户原话核对。设置和恢复用法见[流程引导接入](../../README.md#流程引导接入)。不调用本模块的应用也可自行呈现相同的状态和决定。

## 没完成时

缺少当前状态、成果内容、明确答复或修改所需材料时，仅说明缺项并提出一个最必要的问题，不返回批准决定。版本变化、执行失败或结果不明时说明阻碍，交执行入口或负责模块处理，不能以重新调用整个项目代替恢复。
