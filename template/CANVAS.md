# 画布

模块和连接写在 `module.json` 和 `connections.json` 里，手改容易漏、容易错，也看不出整体长什么样。画布是把这些画出来的图形界面：每个模块一个节点，每条连线就是 `connections.json` 里的一条连接，拖线就是在写连接。

## 启动

```bash
node canvas.mjs
```

在智能体内置的浏览器里打开终端显示的地址（如 `http://127.0.0.1:端口`）。

## 能做什么

- **拖线建连接**：从模块的输出圆点拖到另一个模块的输入圆点。松开后填“传的是什么”，可以再填“什么时候才传”。点击连线改，右键删。拖动标题挪位置。改完点“保存连接”才写盘。
- **打包**：左侧勾选两个以上模块，填标识和名称，先看预览（会移动哪些目录、生成哪些接口、改多少处链接），确认后才执行。打包后新组合是 `pending`，补齐职责、输入输出和检查标准再改成 `ready`。
- **看说明**：点左侧成员，或双击基础模块，可以读它的 README 和 VALIDATION。双击组合会进入它内部看连接。

## 会改哪些文件

画布只改两样东西：各层的 `connections.json`（真实连接）和根目录的 `canvas-layout.json`（节点位置）。删掉 layout 不影响任何连接。

`workspace/` 里是运行时数据，画布不读也不改。

保存前会核对文件有没有被别人改过，改过就拒绝覆盖。服务只监听本机。
