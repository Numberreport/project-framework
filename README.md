# project-framework

人与 AI 协作的方法模板：把复杂的事情简单化，把简单的事情流程化。

适合让 AI 长期做的项目，不限编程。项目照 `template/` 搭。

智能体先读[模板规则](template/AGENTS.md)。模板复制到新项目后，读取新项目根目录的 `AGENTS.md`。

## 怎么用

1. 把 `template/` 的内容全部复制到新项目根目录，含 `.gitignore`、`.gitattributes`。
2. 在新项目里 `git init`，跑 `node check.mjs`。需要 Node 18+。

根目录放项目本身的东西，`modules/` 下每个目录是一个模块，默认平铺。只有多个模块要凑成一项任务时，才在该模块下再建 `modules/`。

项目跑起来以后，每个任务的最新状态和产物都放在根目录的 `workspace/`，一个任务一个子目录。这个目录不进版本管理。

模板带一个画布，用来拖线建连接、把几个模块打成组合、查看各模块的说明，用法见 `template/canvas/README.md`。

正式画布从底层结构生成，结构变更须同步受影响的实现，再核对画布。`template/run.mjs` 可按正式连接安排程序和 AI 模块接力；既有项目也可保留原入口，但须验证实际调用与正式结构一致。接入方式见 [正式执行](template/README.md#正式执行)。草稿仍独立保存，只供试改。

模板带可选的流程引导，支持设置确认位置、暂停保存和恢复接力。接入方法见 [流程引导接入](template/README.md#流程引导接入)。
